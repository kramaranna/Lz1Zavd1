### Відповіді на КЗ
1. Потрібен для побудови графіків; основні властивості: Series, ChartAreas; методи: Points->AddXY, Points->Clear.

2. Це команда для повторення певної дії кілька разів.

3. Спочатку перевіряється умова, а якщо вона істинна — виконується тіло циклу.

4. Спочатку виконується тіло циклу хоча б один раз, а потім перевіряється умова.

5. Виконується із заданою кількістю повторень за допомогою лічильника, кроку та умови.

6. Для дострокового переривання (виходу) з циклу.

7. Для пропуску поточної ітерації і переходу до наступного кроку циклу.

8. За допомогою властивості ChartType; основні значення: Line, Column, Point.

9. Color — для кольору, BorderWidth — для товщини лінії.

10. Це точки на графіку, що показують конкретні значення; налаштовуються через властивості MarkerStyle, MarkerSize тощо.

11. Через властивість LegendText або зміну назви самої серії в колекції Series.

12. Додати заголовок через колекцію Titles компонента Chart.

13. Закріпити краї компонента за допомогою прапорців Top, Bottom, Left, Right у властивості Anchor.

14. Для форматування відображення чисел (кількості знаків після коми) на осях координат.

15. Clear очищує старі точки, AddXY додає нові точки у циклі для побудови графіка.
