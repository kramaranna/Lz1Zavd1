 Програма виконує табулювання математичної функції та візуалізує її результати на графіку. Вона працює шляхом зчитування числа введення через текстове поле і розрахунку значень на заданому відрізку з кроком. На головному екрані розташовані компоненти: TextBox для введення числа, ListBox для таблиці, Chart для графіка та кнопки керування.
